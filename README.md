# Airbnb Clone - PlayPower Labs Assignment

A responsive Airbnb-inspired web application developed as part of a technical assignment for PlayPower Labs.

## Overview

This project is a frontend web application inspired by the Airbnb platform. It demonstrates the implementation of a modern property-listing interface with reusable components, responsive design, and a clean user experience.

## Features

- Airbnb-inspired user interface
- Responsive design
- Property listing interface
- Property images and details
- Search and browsing experience
- Reusable React components
- Modern frontend architecture
- Mobile-friendly layout

## Technologies Used

- Next.js
- React
- TypeScript
- JavaScript
- CSS
- HTML
- Node.js
- npm
